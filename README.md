# Smart Gaming Cafe Session Management and Automated Billing System

A web-based system for a PS4/PS5 gaming shop. It replaces the paper tally book where coordinators start and end sessions. The system counts games or runs the timer, works out the bill and records cash and M-pesa payments. Admins manage stations, games, prices and staff and review revenue

## Tech

- Python, Flask, Flask-SQLAlchemy
- MySQL (via XAMPP) for development, with a planned move to postgreSQL
